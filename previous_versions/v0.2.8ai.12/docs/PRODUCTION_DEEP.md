# Production Clean Deep — 0.2.8ai

0.2.8ai writes only `.yuaz-0.2.8ai`. Existing `.yuaz-alpha8-rc4-3-ai3` and `.yuaz-alpha8-rc3-3` states are read-only fallbacks and are fully archived before a new 0.2.8ai Deep run.

A new Deep run rebuilds analysis from source WAVs, validates Stage A/B/C, and pins a compatible AI foundation by copy. If no new 0.2.8ai state exists, Deep is not required merely to render an already prepared AI.3 voicebank.
